## 남은 문제: 숨겨진 치매 답이 계산을 덮어씀

### 공개 사이트 재현 순서

1. 65세 미만 → 해당 질병 '해당 없어요' → 치매 진단 '아니에요'.
2. 건강보험, 아직 신청 안 함. 신체·재활은 모두 독립생활, 의료 처치·기억력·행동은 없음, 함께 사는 가족이 충분히 돌봄, 집에서 생활, 주거 문제 없음으로 완료.
3. '답 고치기' → 나이 65세 미만 유지 → 질병을 '치매'로 변경.
4. 치매 진단 질문은 생략됨. 나머지는 같은 답으로 끝까지 진행.
5. 예상 등급은 **등급외**로 나옴.
6. '처음부터'로 답을 비우고 **동일한 최종 선택**(65세 미만·치매·독립생활 등)을 입력하면 예상 등급은 **인지지원등급**으로 나옴.

같은 최종 선택에 대해 답변 이력 때문에 결과가 달라진다. 공개 사이트의 두 결과 화면과 로컬 엔진에서 모두 확인했다. 이는 공단의 실제 등급을 판단한 것이 아니라 해당 서비스 내부 결과의 일관성 문제다.

### 원인

`web/src/engine/answers.ts`의 `expandAnswers`는 처음에 원래 답 전체를 복사한다. 숨겨진 질문은 변환을 건너뛰지만 이미 복사한 답은 제거하지 않는다. 질병의 `sets`가 치매 진단을 설정하려 해도 89행의 `raw[k] === undefined` 조건 때문에 과거 `dementia=none`이 있으면 `diagnosed`로 반영되지 않는다.

재현 최소 입력:

```json
{ "age": "under65", "disease": "dementia", "dementia": "none" }
```

현재 `visibleSteps`는 치매 진단 질문을 숨기지만 `expandAnswers(...).dementia`와 채점 입력은 `none`이다. 과거 `dementia` 키가 없는 동일 사례는 `diagnosed`가 된다.

현재 추가 테스트는 과거 치매 답이 없는 상태를 검사하므로 이 경로를 잡지 못한다. 숨겨진 답을 계산에서 제외하고, '현재 유효한 답이 같으면 답변 수정 이력과 무관하게 결과가 같다'는 회귀 테스트가 필요하다. `none` 외 `suspected`·`unknown` 및 다른 조건부 답도 같은 원칙으로 확인하는 것이 좋다.

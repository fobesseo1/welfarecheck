# 기관 정보 데이터 계획 (2026-11-03 조사)

목표: 전국 재가·주야간보호·요양원·요양병원 정보를 보호자가 한곳에서 보게 한다. 지도는 사용자의 별도 시스템(네이버 지도 연동)을 가져온다.

API 원문 명세는 `docs/api-specs/` 에 저장했다 (공공데이터포털 페이지·활용가이드에서 추출).

## 1. 쓸 API와 실제 항목

키는 `.env.local` 의 `DATA_GO_KR_SERVICE_KEY` 하나. API마다 활용신청 필요. 개발계정 트래픽 10,000건/일(기능별), 최대 30tps. 운영계정은 활용사례 등록 후 증가 신청.

## 2. 공공 API에 없는 것 → 다른 방법

| 필요한 것 | 상황 | 방법 |
|---|---|---|
| 장기요양기관 **평가등급(A~E)** | 기관별 등급 API 없음. 공단 홈페이지 기관찾기에서만 공개, data.go.kr에는 등급별 집계(15124194)만 | 후속 조사: 공단 공개 자료·정보공개청구 검토. 당장은 등급 칸 없이 시작 |
| 좌표 | 공단 API에 좌표 없음(주소만) | 지도 시스템에 주소→좌표 변환 요청 |
| 폐업 여부 | 검색 API는 현재 지정 기관만 나오는 것으로 보임 | 매주 다시 받아 사라진 기관을 '정보 없음' 처리. LOCALDATA는 후순위 |
| 치매안심센터 | 15021138 표준데이터(좌표 포함) | 같은 키로 받기 |

## 3. 수집 규모와 순서

1. 검색 API로 시도(17)×유형 목록 → 전국 기관기호 목록 (수백 건 호출)
2. 기관마다 상세 기능 호출. 장기요양기관 약 2~3만 곳 × 필요한 기능 6~7개. 개발계정(기능별 10,000/일)이면 기능별로 2~3일. 입소인원·비급여는 자주 바뀌므로 주 1회, 나머지는 월 1회.
3. 요양병원 약 1,400곳: 목록 + 평가 + 상세 일부 → 하루 안에 끝남.
4. 합쳐서 `data/facilities/` 에 시군구별 JSON으로 저장 → 정적 사이트가 읽는다.

## 3-1. 실제 호출로 확인한 것 (2026-11-03)

- 수집 스크립트: `tools/facilities/collect.mjs` (probe · list · detail · hosp · build). 원본은 `data/facilities/raw/`(커밋 안 함).
- 전국 장기요양기관 **30,465곳**(기관기호 기준). 서비스별: 방문요양 18,854 · 방문목욕 11,002 · 요양원(입소) 6,481 · 주야간보호 5,798 · 복지용구 2,156 · 방문간호 975 · 단기보호 98. 치매전담 유형 포함 420곳, 여러 서비스를 함께 하는 곳 12,824곳.
- **시도코드 12 = 광주+전남 통합**(2026). 29·46으로 물으면 0건. 강원 51, 전북 52 (구 코드 42·45는 0건).
- 목록 API의 numOfRows=1000이 동작한다.
- 상세 API 일반현황에 글자 주소(`adminAddr`, 명세표에는 없음)와 도로명코드(12자리)·건물 본번·부번·우편번호가 온다. 화면에는 `adminAddr` 를 쓰고, 좌표는 아래 방법으로 붙인다. (처음엔 글자 주소가 없다고 잘못 봤음)
  - **쓰는 길(2026-11-03 결정): 우체국 우편번호 DB + 브이월드 지오코더** (`collect.mjs geo-addr`). 주소정보누리집(business.juso.go.kr)은 API 키·자료 내려받기 모두 심사가 있어(좌표 API 첫 신청 '부적합') 쓰지 않는다.
    - 우체국 [우편번호 내려받기](https://www.epost.go.kr/search/zipcode/areacdAddressDown.jsp) '지역별 주소 DB'(zipcode_DB.zip, 약 115MB, 로그인·심사 없음, 2026.10.13 고시본) → `data/facilities/raw/epost/` 에 풀기. 칼럼에 도로명코드·도로명·지하여부·건물본번·부번·지번이 있어 공단 값과 바로 맞는다(첫 시험 8,028곳 중 7,978곳 글자 주소 생성).
    - 글자 도로명주소로 브이월드 `req/address getcoord type=road`, 없으면 지번(`type=parcel`)으로 다시. 결과는 `data/facilities/geocode-cache.json` (위경도·precision·글자 주소·우편번호; 주소가 바뀐 곳만 다시 물음). 지도와 상세 화면에 글자 주소(`addr`)도 같이 쓴다.
    - 우체국 DB는 매월 고시되므로 가끔 새로 받는다.
  - 보조(승인되면): 도로명주소 좌표제공 API(`collect.mjs geo`, `JUSO_COORD_API_KEY`) 또는 출입구 정보 TXT(`collect.mjs geo-file`, `data/facilities/raw/juso/`). 코드는 남겨 둠.
  - 브이월드 데이터 API(LT_C_SPBD 건물, LT_L_SPRD 도로)는 검색 속성이 도로명 '글자'(rd_nm, rn)뿐이라 코드로는 찾을 수 없음을 확인.

# 상담 신청 → 구글 시트 연결하기

상담 신청서(`consult.html`)를 내면 구글 시트에 한 줄씩 쌓이게 하는 방법이에요. 약 10분 걸려요.
연결하기 전까지 사이트의 신청서는 "상담 접수를 준비하고 있어요. 곧 열려요."라고만 안내하고 아무것도 보내지 않아요.

## 1. 시트 만들기 (사용자가 직접)
1. 상담용 구글 계정으로 https://sheets.google.com 에서 새 스프레드시트를 만들고 이름을 정해요. (예: 요양원 길잡이 상담)
2. 이 시트는 **공유하지 마세요.** 상담원에게만 따로 권한을 줘요. 연락처와 (동의한 경우) 건강 관련 정보가 들어가요.

## 2. 받는 코드 넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 열어요.
2. `Code.gs` 내용을 모두 지우고, 이 저장소의 `tools/consult-sheet/Code.gs` 내용을 붙여 넣고 저장해요.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**.
2. 실행: **나**, 액세스 권한: **모든 사용자**. (누구나 신청서를 낼 수 있어야 해서예요. 시트 자체는 공개되지 않아요.)
3. 처음 한 번 구글 권한 확인 화면이 나오면 허용해요.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## 4. 사이트에 넣기
- `web/src/site.ts` 의 `consultEndpoint: ''` 에 복사한 주소를 넣어요. (Claude 에게 "이 주소로 연결해 줘"라고 주면 돼요.)
- 같은 파일에 카카오톡 채널 주소(`kakaoUrl`), 대표 전화(`phone`), 회사 정보(`company`), 보관 기간(`retention`)도 정해지면 넣어요. 빈 칸은 화면에서 감춰져요.

## 시트 모양
| 접수 시각 | 지역 | 동네 | 필요한 도움 | 직접 적은 내용 | 연락 방법 | 휴대폰 | 호칭 | 3분 체크 결과 요약 | 건강정보 동의 | 개인정보 동의 | 상태 | 담당자 | 연락한 날 | 연결한 기관 | 메모 |
- 앞쪽은 신청서가 채우고, **상태(신규 → 연락함 → 매칭 중 → 연결 완료)**부터 오른쪽은 상담원이 적어요. 이 기록이 매칭 데이터가 돼요.
- "3분 체크 결과 요약"은 보호자가 **따로 동의한 경우에만** 채워져요(건강 관련 정보는 민감정보라 별도 동의가 필요).

## 서비스 시작 전에 꼭
- 개인정보처리방침(받는 항목·목적·보관 기간·삭제 요청 방법)을 사이트에 올리고 `retention` 을 맞춰요.
- 기관에 연락처를 넘길 때는 그때 보호자에게 따로 동의를 받아요(제3자 제공).

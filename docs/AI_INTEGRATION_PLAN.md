# 할 일: 다른 AI(Claude·ChatGPT·Gemini)에서 요양원 길잡이를 쓰게 하기

작성: 2026-10-03 · 상태: **아직 시작 안 함 (계획만)**

## 목표
보호자가 Claude·ChatGPT·Gemini 같은 AI와 대화하다가 "엄마가 요양원에 갈 수 있을까?"를 물으면,
그 AI가 등급을 **스스로 지어내지 않고 우리 계산 엔진을 불러** 같은 규칙·점수표로 나온 결과를 전하게 한다.

원칙과의 관계
- 원칙 1(AI API를 쓰지 않는다)과 충돌하지 않는다. 우리가 AI를 부르는 게 아니라 AI가 우리 계산기를 부른다. 계산은 계속 규칙·점수표로만 한다.
- 결과에는 항상 "참고용 추정 · 등급과 급여는 국민건강보험공단이 결정" 문구를 함께 돌려준다(원칙 4).
- 받은 답은 저장하지 않고 계산만 한다. 어르신 건강 정보라서 기록(로그)에도 남기지 않는다.

## 방법 (쉬운 순서)

### ① 답을 미리 채운 링크 + `llms.txt` — 먼저 할 것 (1~2일)
- 링크 예: `https://fobesseo1.github.io/welfarecheck/#age=over65&dementia=diagnosed&grade=none`
  - 답은 반드시 `#` 뒤에 둔다(서버로 전송되지 않음). `?` 쿼리에 넣지 않는다.
  - 열면 미리 채운 답을 보여 주고, 빠진 질문부터 이어서 묻는다. 질문 ID·선택지 값은 `data/questionnaire.json` 그대로.
- 사이트 루트에 `llms.txt`: 도구가 하는 일, 질문 ID와 선택지 값 목록, 링크 만드는 법, "공식 판정 아님" 안내.
- 장점: 별도 등록 없이 세 회사 AI 모두 활용 가능. 한계: AI가 우리 사이트를 알아야 함(검색 노출에 의존).

### ② MCP 서버 — 핵심 (한 번 만들면 세 곳 모두)
- MCP(Model Context Protocol): AI가 바깥 도구를 부르는 표준 규격. 2026년 현재 Claude·ChatGPT·Gemini가 지원.
- `web/src/engine/`(계산 엔진)을 그대로 감싸 도구로 공개. 예:
  - `list_questions` — 질문·선택지 목록(질문 순서와 분기 포함)
  - `estimate_grade` — 답 → 예상 등급 범위·근거 영역 점수
  - `check_facility` — 요양원(시설급여) 이용 조건과 ①②③ 사유 가능성
  - `required_documents` — 지금/나중 서류, 신청 경로, 공식 링크
- 서버 필요: GitHub Pages(정적)에는 못 올림 → Cloudflare Workers·Vercel 등 무료 서버. 계정 가입은 사용자가 직접.
- 회사별 (2026-10-03 검색 기준, 실제 작업 전 공식 문서로 재확인)
  - Claude: 커넥터 디렉터리(950개 이상). 등록 전에도 사용자가 "사용자 지정 커넥터"로 주소 추가해 사용 가능. https://claude.com/ko/blog/bringing-mcp-2026-07-28-to-claude
  - ChatGPT: Apps SDK가 MCP 기반. 개발자 모드로 시험 → 앱 디렉터리 제출(2025-12 공개, 심사 있음). https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/
  - Gemini: 일반 앱의 사용자 지정 MCP 연결, Gemini Enterprise 연결이 있다고 함 — 외부 블로그 기준이라 공식 확인 필요. https://tallyfy.com/how-to-list-mcp-server-google-gemini/

### ③ GPTs·Gems·프로젝트에 자료만 넣기 — 하지 않음
- 계산을 그 AI가 직접 하게 되어 등급을 틀리게 추정할 수 있다. 원칙 3(근거 DB의 규칙만)과 맞지 않는다. 쓰더라도 계산은 ②의 도구를 부르게 한다.

### ④ 검색 노출 (AI 검색 인용)
- 질문별 안내 글(예: "3등급도 요양원 갈 수 있나요?" — 고시 제2조② 근거)을 정적 페이지로. 지금 사이트는 한 화면 도구라 AI가 읽을 글이 거의 없다.

## 시작 전 준비물

- 인증된 개발자 계정(OpenAI 등)
- 아래 "먼저 고칠 버그"를 고친 뒤 시작 — AI가 결과 첫 줄만 전하면 잘못된 안내가 그대로 퍼진다

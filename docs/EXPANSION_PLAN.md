# 확장 기획: 요양원만이 아니라 "돌봄 전체"를 연결 (2026-10-06 초안)

## 한 줄 요약
지금은 "요양원에 모실 수 있을까?" 하나에 맞춰져 있다. 이것을 **"부모님이 조금 불편해졌을 때부터 요양원까지"** 단계별로 넓힌다.
- 잠깐 간병
- 집으로 오는 방문요양
- 낮에만 다니는 주간보호(데이케어)
- 며칠 맡기는 단기보호
- 요양원

**지금 잘 되는 3분 체크(점수 계산·등급 추정·서류 안내)는 그대로 두고, 그 위에 입구와 결과 화면, 상담만 넓힌다.**

---

## 1. 바꾸지 않는 것 (지금 잘 되는 것)
- 3분 체크의 질문, 52개 항목 점수 계산, 등급 추정 엔진(`engine/decide.ts`, `scoring.ts`)과 테스트 154개
- 요양원 입소 조건 판단(R-FAC-01~08), 서류·절차 안내, 숨겨진 질문 처리, 저장·이어하기
- 원칙: LLM 없음, 객관식, 근거 DB에 있는 법 기준만 사용, "참고용 추정" 문구 표시, 기관 소개비 받지 않음

## 2. 보호자의 상황 → 맞는 돌봄 지도
| 보호자가 겪는 상황 | 맞는 돌봄 | 장기요양등급 필요? | 비용 | 우리가 할 일 |
|---|---|---|---|---|
| 입원·수술 뒤 며칠~몇 주 곁에 있어 줄 사람이 필요 | **간병** (병원·집) | 필요 없음 | 전액 개인 부담. 개인 간병보험이 있으면 보험사 지원 | 상황 정리 + 상담 연결 |
| 혼자 씻기·식사·집안일이 조금 버거워짐 | **방문요양**, 방문목욕 | 필요 (1~5등급) | 재가 본인부담 15% | 등급 체크 → 가까운 센터 연결 |
| 낮에 혼자 계시면 걱정, 기억력이 떨어짐 | **주간보호(데이케어)** | 필요 (1~5등급, 인지지원등급) | 재가 본인부담 15% + 식비 | 등급 체크 → 센터 연결 |
| 가족이 여행·입원 등으로 며칠 못 돌봄 | **단기보호** | 필요 (월 9일 이내, R-SHORT-01) | 재가 본인부담 15% | 안내 + 연결 |
| 집에서 돌보기 어려움 | **요양원** | 1·2등급, 3~5등급은 조건부 | 시설 본인부담 20% + 식비 등 | 지금 하는 일 |
| 치료가 계속 필요함 | 요양병원 | 등급과 무관 (건강보험) | 건강보험. 2027년부터 일부 병원은 간병비도 건강보험 예정 | **안내만** (의료법상 소개비 금지, 진료 권유 문구 쓰지 않음) |

## 3. 화면 기획

### 3-1. 홈 첫 화면: "어떤 도움이 필요하세요?" 입구 4개
제목 아래에 상황 카드 4개를 둔다. 누르면 해당 안내로 가고, 결국 3분 체크나 상담으로 모인다.
1. **잠깐 간병이 필요해요** (입원 중·퇴원 후)
2. **집에서 도움을 받고 싶어요** (방문요양·방문목욕)
3. **낮에만 맡기고 싶어요** (주간보호)
4. **요양원을 알아보고 있어요** (지금 흐름)

- 제목 후보 (결정 필요): 지금 "부모님을 요양원에 모실 수 있을까요?" → "부모님 돌봄, 어디서부터 시작할까요?"
  - 요양원 제목이 지금 반응이 좋다면, 제목은 두고 카드만 추가하는 방법도 있다.
- "돌봄은 이렇게 나뉘어요" 구역에 **간병** 카드 추가 (지금은 요양원·주간보호·방문요양 3개).

### 3-2. 3분 체크: 질문은 그대로, 시작과 끝만 조금
- **시작**: 첫 질문 앞에 "지금 가장 필요한 도움"을 하나 고르게 한다(위 4개 + 잘 모르겠어요). 객관식이고 건너뛸 수 있다.
  - 홈에서 고른 카드는 미리 채워진다 (`check.html#need=home` 방식. 지금 `#age=` 미리 채우기와 같은 구조).
  - 이 답은 점수에 들어가지 않는다. 결과 화면에서 무엇을 먼저 보여 줄지만 정한다.
- **간병만 필요한 경우**: 등급과 무관하므로 짧은 갈래로 보낸다.
  - 몇 가지 질문 → "간병은 등급 없이 바로 쓸 수 있어요"
  - 비용과 개인 간병보험 확인 방법을 안내하고 상담을 연결한다.
  - 다만 "장기간이면 장기요양등급도 같이 신청해 보세요"라고 3분 체크를 권한다.
- **결과 화면**: 지금 "요양원 입소" 중심 판정 카드를 **"이용할 수 있는 돌봄" 표**로 넓힌다.
  - 예상 등급별로 방문요양 / 주간보호 / 단기보호 / 요양원 가능 여부를 ○·조건부·✕로 보여 준다.
  - 고른 "필요한 도움"을 맨 위에 둔다.
  - 지금 요양원 판정 카드는 그 표의 한 줄로 그대로 남는다(기존 문구·규칙 재사용).
  - 등급이 안 나올 것 같으면(등급 외): 장기요양 대신 지자체 노인맞춤돌봄서비스 안내를 검토한다. 근거 DB 추가가 필요하다.

### 3-3. 상담 신청
- "필요한 도움" 선택지 확장: 등급 받기 준비 / **간병** / **방문요양** / **주간보호** / 요양원 / 아직 모르겠어요 / 직접 입력
- **간병**을 고르면 추가로 묻는 것:
  - 언제부터 필요한지 (오늘·내일 / 이번 주 / 아직)
  - 병원인지 집인지
  - 간병은 급한 경우가 많다. 그래서 "운영 시간 안에는 바로 연락" 문구를 따로 둔다.
- 결과 요약 첨부와 민감정보 동의는 지금 방식 그대로 둔다.

## 4. 연결 방식과 돈 (법 기준)
| 돌봄 | 법 | 우리 방식 |
|---|---|---|
| 방문요양·주간보호·단기보호·요양원 (장기요양기관) | 노인장기요양보험법 제35조제6항, 위반 시 제67조 | **보호자 무료 연결, 기관 소개비 받지 않음**. 고정 광고만, 추천과 광고는 분리 (지금 원칙 5 그대로) |
| 요양병원 (의료기관) | 의료법 제27조제3항 | 연결하지 않고 **안내만** |
| 간병 (일자리 소개) | 직업안정법 | 1단계는 무료 상담·안내만. 수수료를 받으려면 **유료직업소개사업 등록**이 필요하다 (보호자 측 30% 이하, 간병인 측 1% 이하 고시). 다른 간병업체로 넘기고 건당 돈을 받는 방식도 직업소개로 볼 수 있어 등록 전에는 하지 않는다 |
| (먼 미래) 직접 운영 | 장기요양기관 지정 | 방문요양·주간보호센터를 직접 운영하면 보험 급여가 수익이 된다 (케어닥 방식). 별도 결정 사항 |

## 5. 근거 DB에 더해야 할 것 (코드보다 먼저)
- 재가급여 종류와 정의: 방문요양·방문목욕·방문간호·주야간보호·단기보호·기타재가(복지용구). 근거는 법 제23조, `sources_raw/01`
- 등급별 이용 가능 급여. 1~5등급은 재가급여 이용 가능, 인지지원등급은 주야간보호·단기보호·기타재가(R-FAC-03 있음). 고시 `sources_raw/04`로 확인
- 등급별 월 한도액(2026 고시). 결과 화면 "한 달에 대략 이 정도 쓸 수 있어요"용. 고시 원문이 없으면 표시하지 않는다
- 간병: 법 기준이 아니라 **안내 문구**로 `guide_content.json`에 둔다 (비용 전액 부담, 개인 간병보험 확인, 2027 요양병원 간병비 건강보험 예정은 확정 뒤 반영)
- 모든 새 규칙은 `OFFICIAL_VERIFIED`가 된 것만 자동 판단에 쓴다

## 6. 단계
| 단계 | 내용 | 기존 기능 영향 |
|---|---|---|
| **1단계 (작게, 바로)** | 홈 입구 카드 4개, "돌봄 종류"에 간병 추가, 상담 선택지 확장(간병·방문요양·주간보호) | 없음 |
| **2단계** | 근거 DB에 재가급여 규칙 추가 → 결과 화면 "이용할 수 있는 돌봄" 표, 3분 체크 시작에 "필요한 도움" 질문 | 결과 화면 위쪽만 바뀜. 엔진 그대로. 테스트 추가 |
| **3단계** | 간병 짧은 갈래, 급한 간병 상담 흐름, 지역별 기관 목록(공단 공개 데이터 검토) | 별도 화면 |
| **나중** | 간병 유료직업소개 등록, 직영 센터 여부 결정, 법률 검토 | — |

각 단계 끝에 기존 테스트 154개가 그대로 통과해야 하고, RESULT_SAMPLES.md 17개 결과가 바뀌지 않아야 한다(요양원 판정 부분).

## 7. 결정 사항 (2026-10-06)
1. 홈 제목은 **"부모님 돌봄, 어디서부터 시작할까요?"** 로 넓힌다.
2. 간병은 일단 무료 상담으로 시작하고, 나중에 유료직업소개사업을 등록한다.
   - 단, 조사 결과 영리 회사는 무료로도 "특정 간병인을 계약되게 연결"하면 안 된다(직업안정법 제18조, [EXPANSION_LEGAL_RESEARCH.md](EXPANSION_LEGAL_RESEARCH.md) 6절).
   - 그래서 등록 전까지는 **간병 정보 안내 + 장기요양·지자체 돌봄 연결**까지만 한다.
   - 간병 **업체 목록**(상호·지역·연락처·요금)을 보호자에게 보여 주는 것은 해도 된다고 보고 진행한다. 문제가 생기면 바로 내린다(사용자 결정). 간병인 개인 프로필이나 구인공고, 특정 간병인 매칭은 하지 않는다.
3. 순서: 근거 조사([EXPANSION_LEGAL_RESEARCH.md](EXPANSION_LEGAL_RESEARCH.md)) → 근거 DB 반영 → 1단계 → 2단계.

**켜고 끄는 법**
- 관리자 미리보기: `admin.html`에서 켜면 그 브라우저에서만 보인다. 화면 오른쪽 아래에 "관리자 미리보기 중" 표시가 뜬다.
- 모두에게 켜기: `web/public/features.json`에서 값을 `true`로 바꿔 커밋한다. 몇 분 뒤 반영된다.
- 업체·간병인 목록의 `(예시)` 항목은 실제 정보로 바꾼 뒤에 켠다. 예시가 남은 채로 켜면 테스트가 배포를 막는다.
